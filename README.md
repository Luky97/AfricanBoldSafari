# AFRICAN BOLD SAFARI Website

A React/Vite website for **AFRICAN BOLD SAFARI** with premium safari styling, Tanzania destinations, sample safari packages, gallery lightbox, WhatsApp CTA, and a simple inquiry form.

## Run Locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173/
```

For a fixed local URL, run:

```bash
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Open:

```text
http://127.0.0.1:5173/
```

## Build

```bash
npm run build
npm run preview
```

## Main Files

- `index.html` - Vite HTML entry
- `src/main.jsx` - React entry point
- `src/App.jsx` - AFRICAN BOLD SAFARI website content and interactions
- `src/App.css` - responsive layout, safari styling, and animations
- `src/index.css` - tiny global root styles
- `public/images/african-bold-safari-logo.svg` - official website logo asset
- `public/logo.svg` and `public/favicon.svg` - mirrored logo/favicons used by the app

## Logo

The website logo is served from `public/images/african-bold-safari-logo.svg` and mirrored to `public/logo.svg` plus `public/favicon.svg`.
